# Viz Résumé: Nishad Rashid Mahi

**Tool:** Tableau Public · Python (data preparation)
**Live résumé:** *coming soon on [Tableau Public](https://public.tableau.com/app/profile/nishad.rashid.mahi)*

A one-page interactive résumé built in Tableau. It shows my experience, education, skills and portfolio, and every skill on it is backed by a project you can open.

## What makes it different

Most visual résumés rate skills by feel ("Python: 4 out of 5"). On this one, **each skill's slice in the wheel is as long as the number of my five portfolio projects that used it**. Data cleaning, Python, statistics and business recommendations appear in all five; machine learning and Excel in one each. Every claim can be checked against the project it came from.

| Section | What it shows | How it's built in Tableau |
|---|---|---|
| **Skills wheel** | 9 skills, slice length = projects that used the skill (out of 5) | Polygon marks from pre-calculated points, labels on a dual axis |
| **Tools** | The 10 tools used across the projects | Square marks in a two-column grid |
| **Experience** | Every role and degree from 2017 to now, in three lanes: education, operations, analytics | Vertical Gantt bars on a reversed date axis, coloured by type of role |
| **Education** | MBA, BBA and certifications, as a map or a table | A parameter switch with dynamic zone visibility |
| **Portfolio** | My five projects, each with its headline finding | Image objects that link to each dashboard or GitHub repo |

## Data

| File | One row per | Notes |
|---|---|---|
| [`data/projects.csv`](data/projects.csv) | project | Headline finding, records, dashboard and GitHub links |
| [`data/skills_by_project.csv`](data/skills_by_project.csv) | skill × project | `used` = 1 if the project used the skill. The source of the wheel |
| [`data/skills_wheel.csv`](data/skills_wheel.csv) | point on a shape | Generated by [`python/build_wheel.py`](python/build_wheel.py) |
| [`data/tools.csv`](data/tools.csv) | tool | Grid position |
| [`data/experience.csv`](data/experience.csv) | role or degree | Dates, type of role, lane and the short label shown on the timeline. A blank end date means current |
| [`data/education.csv`](data/education.csv) | degree | Institution, years, city and country (for the map) |
| [`data/certifications.csv`](data/certifications.csv) | certification | |

To rebuild the wheel after changing `skills_by_project.csv`:

```bash
python3 python/build_wheel.py
```

## Design

- **Palette:** ink `#1F2430`, tangerine `#F26B3A`, grey `#9AA0AE`, peach `#FBD0BE`. One accent colour, used for analytics work and for the skills, so the eye goes to the evidence first.
- **Canvas:** fixed 1600 × 900. The frame, photo and section headings are one background image ([`assets/background.png`](assets/background.png)); every chart and number is a Tableau object on top of it.
- **Layout** inspired by Damola Ladipo's Tableau viz résumé. The content, data and skills method are my own.
